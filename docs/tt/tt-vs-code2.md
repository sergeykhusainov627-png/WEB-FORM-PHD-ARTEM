- Прочие аналитики → Дата проведения ГТМ (`календарь`)

- Данные показателя → Вид показателя (`RDSD_GROUPS`)
- Данные показателя → Формы  отчетов (`PFORM`)
- Данные показателя → Выводить ТЭП-источники (`чек-бокс, без справочника`)

- `DICT_DATA_TYPE` «Тип данных для значений ТЭП»
- `RDSD_INDS` «ТЭП (заголовок, период действия, владелец)»
- `RDSD_SP` «Структурные подразделения»
- `RDSD_ZPHD_DOG` «Договор Энерго»
- `RDSD_ZPH_OPLST` «Структурные особенности пласта»

## E. Верхний уровень СЭ (лист «Селекционный экран»)

- **Поле СЭ** — Описание (Справочник)
- **Год** — по умолчанию текущий год (DIC_PHD_DATE_APPROVING)
- **СП** — по умолчанию СП пользователя. Многократный выбор.  Доступ к выбору СП согласно полномочиям* (RDSD_PLANT)
- **Тип данных** — по умолчанию План ID 0000000001 (DICT_DATA_TYPE)
- **ТЭП** — не обязательный, многократный выбор (RDSD_INDS)
- **Условия выборки:** — установлен по умолчанию. При выборе данного пункта на экране представлены разделы, в которых перечислены поля для фильтрации выбираемых данных (все разделы и их поля со справочниками см. на листе "Разделы СЭ-Условия выборки")
- **Поля для вывода:** — выводятся разделы и наименования полей, которые необходимо вывести в отчете (разделы и перечень полей см. на листе СЭ-поля для вывода)
- **Выводить коды аналитик** — при установке данного чек-бокса к выбранным полям  в разделе "Поля для выбора"  в отчете добавляются поля с кодами значений и справочника (поля и их источник данных см. на листе "Вывод полей в отчете")
- **Выводить информацию по статусам:** — при установке данного чек-бокса к выбранным полям  в разделе "Поля для выбора"  в отчете добавляются поля с кодами значений и справочника (поля и их источник данных см. на листе "Вывод полей в отчете")

  * Доступ к выбору СП согласно полномочиям:
  Для группы ролей PHD_ADMIN  или PHD_CURATOR_*** поле «Структурное подразделение» доступно для выбора, любое значение из справочника.
  Для остальных групп ролей структурное подразделение заполняется автоматически в соответствии со значением в основной записи пользователя, изменение на СЭ на другое значение не допускается.
