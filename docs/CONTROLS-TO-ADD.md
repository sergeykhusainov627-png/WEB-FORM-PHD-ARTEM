# Контролы, которые нужно добавить в дизайнере формы

**Зачем.** Модуль ссылается на контрол по имени: если компонента на форме нет, при открытии режима
редактирования формы платформа падает с «Ошибка сервера Unknown Error». Поэтому код ссылается только
на те контролы, которые были в исходном модуле; всё остальное закомментировано и включается
**автоматически**, как только компонент появится.

**Как добавлять (для каждого контрола):**

1. Положить компонент на форму и задать ему имя **точно как в таблице** (имя компонента = имя поля
   в модуле; объявление поля дизайнер добавит сам).
2. Навесить событие **`OnChange`** — дизайнер создаст обработчик `<Имя>OnChange; Begin End Sub;`.
3. Пересобрать модуль из эталона:
   `python tools/patch-webform.py …  &&  python tools/cleanup-unused.py …  &&  python tools/check-webform.py …`
   После этого для контрола автоматически появятся: строка в таблице `InitOutputFieldIds`,
   строка `CollectIfChecked(<Имя>, "<Имя>");` в `RefreshFieldList` и тело обработчика.
4. Для «служебных» чек-боксов (пункты 1–2) дополнительно включатся режимы — код в `RefreshFieldList`
   раскомментируется сам, потому что обработчик уже есть.
