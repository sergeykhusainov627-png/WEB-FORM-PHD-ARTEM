## Правила работы с репозиторием

1. **Не менять переводы строк и кодировку `.fore`** — платформа ждёт UTF-8 без BOM + CRLF.
   В `.gitattributes` для `*.fore` стоит `-text`, поэтому git не конвертирует файлы.
2. **Модуль формы не форматировать целиком** — иначе теряется сопоставимость со стендом и разбор
   (`docs/ANALIZ-TEP-webform.md` ссылается на номера строк).
3. Правки формы — отдельными коммитами с указанием, что именно изменилось по ТТ
   (`docs/TT-vs-CODE.md` — карта «требование → код»).
4. Перед выкладкой на стенд: `node tools/form-inventory.js Fore/WFRM_PHD_ANALISIS_TEP_COPY_FOR_DEV.fore`
   (инвентарь контролов и обработчиков) и линтер `.fore` из проекта «Планировщик задач»
   (`F:\Scheduler Tasks\tools\fore-lint-check.js`) — ожидается 0 реальных замечаний.

## Состояние на момент снимка (кратко)

* Механизм кнопки «Ок» рабочий: гиперссылка в ячейке A1 отчёта, строка действия собирается
  `COpenHyperlink.Generate` из менеджера параметров; ручной разбор строки в модуле избыточен.
* По ТТ реализовано: 41 из 57 полей фильтрации, 58 флажков вывода в `P_FIELD_LIST`.
* Не реализовано: чек-боксы «Выводить коды аналитик» и «Выводить информацию по статусам»;
  19 периодов (месяцы/кварталы) с пустыми обработчиками; группы «с начала года» и «корректировки»;
  раздел «Данные показателя» и зависимые выборки (`TBL_IDLNK`, `TBL_ZIDNFORM`, `RDSD_OWNERS`, …);
  2 текстовых поля и 4 календаря; ролевая модель доступа к СП; значения по умолчанию (закомментированы).
* Подробности и таблицы — `docs/TT-vs-CODE.md`.

## Публикация

Репозиторий **публичный** — по решению владельца проекта. В него сознательно включены и технические
требования (`docs/ТТ_Анализ и выгрузка данных ТЭП.xlsx`), и выгрузка окружения
(`export/full_env_web_form_06102026.pefx`), и разборы.

Перед публикацией выполнена проверка на секреты: паролей, токенов, строк подключения в материалах нет
(`password`, `pwd=`, `token`, `secret`, `api_key` — 0 совпадений в текстовых файлах, в `content.xml`
и внутри `.pefx`). Единственные совпадения — слова в комментарии про Git Credential Manager и имя
дизайнерского свойства `isPassword` в выжимке справки.
